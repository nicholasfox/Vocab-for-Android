# 3.1 UI 实作清单

## 共用规格

- 主题：亮色、暗色、跟随系统；不提供自行调整文字或文件夹颜色。
- 背景：亮色 `#F6F7F9`；暗色 `#0F1115`。
- 一般表面：亮色 `#FFFFFF`；暗色 `#191C22`。
- 输入表面：亮色 `#EDF0F4`；暗色 `#262A32`。
- 主色：亮色 `#245FE5`；暗色 `#82AAFF`。
- 内容区块圆角 20dp；输入框、主要操作 16dp；搜索框 28dp；视窗 28dp。
- 按钮最小高度 48dp；选择题最小高度 62dp；栏位保留系统字级与无障碍缩放。
- 除透明毛玻璃导航列外，不添加渐层／装饰性阴影；错误提示保留语意色。

## 验证范围

`ModernScreensTest` 使用实际语法主页、语法库、语法编辑和长文件夹选择清单，检查次级操作、套用、空白处滑动和画面输出。`GreetingScreenshotTest` 验证主页限定的模式切换与翻卡左右滑评分、没有评分按钮。

这些为 Robolectric 测试与画面检查，不等同实体手机上的扫描器、背景朗读或系统浮窗权限测试；正式发布仍使用既有签章与未缩减的扫描建置设置。
